🎵 DryerTone

DryerTone es una red social en la que nuestro objetivo principal es dar a conocer las opiniones de los demás, además que nosotros fomentamos el respeto entre los usuarios y sobre el derecho a la libre expresión, esto es para dar a conocer tu opinión sobre algún tema y decir como te sientes con esa opinión.

✨ Características principales:

1. Crear publicaciones con nombre de usuario, contenido y categoría musical.
2. Explorar publicaciones de diferentes géneros musicales.
3. Buscar publicaciones mediante la barra de búsqueda.
4. Dar Me gusta a las publicaciones.
5. Interactuar con las publicaciones.
6. Compartir publicaciones.
7. Guardar publicaciones.
8. Eliminar publicaciones.
9. Cambiar entre modo oscuro y modo claro.
10. Filtrar publicaciones según su categoría.
11. Contador de caracteres para el formulario de publicación.
12. Interfaz adaptable a diferentes tamaños de pantalla.

🛠️ Tecnologías utilizadas en el desarrollo:

HTML5: Estructura y organización del contenido mediante etiquetas semánticas.

CSS3: Diseño visual, animaciones, efectos, distribución de elementos y adaptación a diferentes dispositivos.

JavaScript: Funcionalidad, interactividad, manipulación del DOM y generación dinámica de publicaciones.

🎼 Categorías musicales

En DryerTone hay categorías que sirven para encontrar mas facilmente publicaciones según la categoría que estes buscando:
1. Rock
2. Pop
3. Synth-Pop
4. Rap
5. Indie (Temporalmente deshabilitada)
6. Lo-Fi
7. R&B

🚀 Pasos para su instalación y ejecución

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir el archivo index.html en un navegador web.
4. Explorar las diferentes secciones y funcionalidades de DryerTone.

También se puede utilizar Visual Studio Code junto con la extensión Live Server para ejecutar el proyecto localmente.

🎨 Diseño

DryerTone utiliza una interfaz moderna con una temática oscura, combinando tonos azules, morados y diferentes efectos visuales para crear una experiencia agradable. Adémas también se puede cambiar el color de tema del oscuro a un claro, con bordes celestes y totalmente blanco.

El diseño incluye elementos como tarjetas de publicaciones, barras laterales, botones interactivos, animaciones y una distribución organizada del contenido.
